# Architecture Decision Records

Esta pasta contém as Architecture Decision Records (ADRs) do projeto.
Para mais informações sobre ADRs, consulte a [referência de Martin Fowler](https://martinfowler.com/bliki/ArchitectureDecisionRecord.html).

As ADRs documentam decisões arquiteturais relevantes, seus respectivos contextos, justificativas e consequências.
